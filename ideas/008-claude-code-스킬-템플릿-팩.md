# Claude Code 스킬·템플릿 팩

- 작성일: 2026-09-24
- 상태: 후보

## 한 줄 요약
이 저장소처럼 실전에서 쓰는 Claude Code 스킬, 프로젝트 템플릿, 프롬프트 모음을 패키지로 판매한다.

## 누가 돈을 내는가 (타깃 고객)
Claude Code를 쓰는 개발자·1인 창업자 (국내 + 해외).

## 왜 Claude가 필요한가
Claude를 도구로 쓰는 방법 자체가 상품이다. 영어 문서화도 Claude로 해결한다.

## 수익 모델
디지털 상품 판매. 기본판은 무료로 공개해 유입을 만들고, 확장판을 유료로 판다.

## 최소 실험 (MVP) 아이디어
- 무엇을 만들까: 이 저장소의 템플릿과 new.py를 정리해 무료 공개 저장소로 올리고 스타 수와 반응을 본다.
- 얼마나 걸릴까: 1주
- 성공 기준: 공개 후 2주 안에 스타 30개 또는 문의 발생
