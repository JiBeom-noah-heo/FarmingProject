# 아이디어 백로그

아이디어 하나당 파일 하나 (`python scripts/new.py idea "제목"`).
아래 표에 한 줄씩 추가하고 점수로 우선순위를 정합니다.

## 평가 기준 (각 1~5점)

- **수익성**: 돈이 될 가능성, 규모
- **실행 난이도**: 혼자, 육아 중 짧은 시간에 할 수 있는가 (쉬울수록 높은 점수)
- **검증 속도**: 1~2주 안에 반응을 확인할 수 있는가
- **콘텐츠 가치**: 과정 자체가 블로그/영상 소재가 되는가
