# 실험: 업무 자동화 외주 (크몽)

- 시작일: 2026-09-24
- 관련 아이디어: [ideas/002](../../ideas/002-크몽-업무자동화-외주.md)
- 상태: 설계 완료 → 사전 점검 대기

## 한 줄 요약
"엑셀에 쌓인 설문·리뷰·문의 글을 AI로 분류·요약해 드립니다"라는 **좁은 서비스 하나**를 크몽에 등록하고,
4주 동안 실제 문의·주문이 들어오는지 확인한다.

## 가설
> 일반 엑셀 자동화는 경쟁이 치열하지만, **글(텍스트)을 AI로 분류·요약**하는 좁은 서비스는
> 신규 판매자도 2주 안에 문의를 받을 수 있을 것이다.

## 왜 이 서비스인가

| 후보 | 장점 | 단점 | 판단 |
|------|------|------|------|
| A. 엑셀 취합·정리 자동화 | 수요가 많고 설명이 쉬움 | 판매자가 많아 가격 경쟁, AI 강점이 없음 | 포트폴리오로만 활용 |
| **B. 텍스트 AI 분류·요약 리포트** | Claude 강점이 그대로 드러남, 차별화, 짧은 납기 | 개념 설명이 필요함 | **선택** |
| C. 웹 데이터 수집(크롤링) | 수요 많음 | 사이트 약관·법적 위험, 유지보수 부담 | 제외 |

B를 고른 이유: 텍스트 분류·요약이 **Claude의 강점**이라 차별화되고, 납품물이 엑셀과 리포트여서
**고객 응대 시간이 짧다**(육아 일정과 맞음). 전자책(ideas/003)에 넣을 사례로도 좋다.

## 성공 기준 (숫자로)

| 시점 | 지표 | 기준 | 미달 시 |
|------|------|------|---------|
| 등록 후 2주 | 문의 수 | 3건 이상 | 제목·썸네일·가격 수정 후 2주 연장 |
| 등록 후 4주 | 주문 수 | 1건 이상 | 서비스를 A(엑셀 취합)로 바꾸거나 실험 종료 |
| 전체 기간 | 주당 작업 시간 | 15시간 미만 유지 | 주문 받는 수를 제한 |

## 실행 계획

### 0단계: 사전 점검 (반드시 먼저)
- [ ] **육아휴직 급여 영향 확인**: 고용센터(☎1350)에 프리랜서 소득 신고 방법 문의 → [research.md](research.md#육아휴직-급여와-소득-활동)
- [ ] 회사 취업규칙의 겸업 금지 조항 확인
- [ ] 크몽 공식 수수료 페이지에서 수수료율 재확인 → `fee_calc.py`에 반영
- [ ] 크몽 판매자 가입 조건(개인/사업자, 정산 방식) 확인

### 1단계: 포트폴리오 만들기 (1주차)
공개 데이터나 직접 만든 가짜 데이터만 쓴다. 실제 고객 데이터는 절대 쓰지 않는다.

1. **설문 주관식 응답 AI 분류·요약** (주력 서비스 시연)
   - 입력: 가상 설문 응답 300개가 담긴 엑셀
   - 처리: Claude API로 주제 분류 + 긍정/부정 + 핵심 요약
   - 출력: 분류 결과 엑셀 + 1장짜리 요약 리포트
2. **여러 엑셀 파일 취합 → 월간 요약표** (기본기 시연)
   - 입력: 지점별·월별 매출 엑셀 여러 개
   - 처리: pandas로 합치고 정리
   - 출력: 요약 시트가 포함된 엑셀 1개

### 2단계: 서비스 등록 (1주차 말)

## 비용

| 항목 | 예상 | 근거 |
|------|------|------|
| 크몽 수수료 | 판매가의 약 22% | `python fee_calc.py` (15만원 → 실수령 약 11.7만원) |
| Claude API (주문 1건) | 약 3~10달러 | 응답 1,000개 기준 추정, 아래 참고 |
| Claude API (포트폴리오 제작) | 약 10달러 이내 | 테스트 반복 포함 |
| 등록비 | 0원 | |

**API 비용 추정** (응답 1,000개, 20개씩 묶어 50번 호출 가정 → 입력 약 25만 토큰, 출력 약 7.5만 토큰)
- Claude Opus 5 ($5 / $25 per 1M): 약 3.1달러
- Claude Haiku 4.5 ($1 / $5 per 1M): 약 0.6달러
- 테스트 재실행까지 감안해도 주문 1건당 판매가의 10% 미만. 모델은 포트폴리오 결과 품질을 보고 정한다.
