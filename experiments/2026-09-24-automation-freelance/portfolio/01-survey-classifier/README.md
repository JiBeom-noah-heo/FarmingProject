# 포트폴리오 1: 설문 응답 AI 분류·요약

엑셀/CSV에 쌓인 주관식 응답을 Claude로 **분류·감성 분석·요약**하고,
**엑셀 결과표 + 분석 리포트**로 만들어 주는 도구입니다. 크몽 서비스의 시연용 포트폴리오입니다.

## 결과물

| 파일 | 내용 |
|------|------|
| `output/sample_survey_분류결과.xlsx` | 시트 3개: **분류결과**(원본 + 주분류·부분류·감성·한줄요약), **카테고리요약**(건수·비율·감성 분포·평균 만족도), **분류기준** |
| `output/sample_survey_리포트.md` | 카테고리별 집계표 + 한눈에 보기, 시급한 문제 Top 3, 강점, 개선 제안 |

## 샘플 데이터

`sample_survey.csv` — 가상의 육아용품 쇼핑몰 '리틀팜 마켓' 고객 설문 100건.
**모두 직접 지어낸 응답**입니다 (`make_sample_data.py`로 다시 만들 수 있음).
배송·포장·가격·앱·고객센터 등 여러 주제가 섞여 있고, 한 응답에 주제가 두 개인 경우, 영어 응답, "없음" 같은 짧은 응답도 넣었습니다.

## 실행 방법

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...        # Windows PowerShell: $env:ANTHROPIC_API_KEY="sk-ant-..."

python classify.py sample_survey.csv --column 주관식응답 --score-column 만족도 \
    --question "리틀팜 마켓을 이용하면서 좋았던 점, 아쉬운 점을 자유롭게 적어 주세요."
```

옵션:
- `--categories "배송,가격·혜택,상품품질"` — 고객이 정한 기준으로 분류 (없으면 AI가 5~8개 제안)
- `--model claude-haiku-4-5` — 더 저렴한 모델 (기본값: `claude-opus-5`)
- `--out-dir 결과폴더` — 결과 저장 위치 (기본값: `output/`)

실행이 끝나면 사용한 토큰과 **API 비용 추정치**가 출력됩니다. 견적 낼 때 그대로 씁니다.

## 동작 방식

```
CSV/엑셀 ──▶ ① 분류 기준 제안 (Claude) ──▶ ② 20개씩 분류 (Claude, JSON 스키마로 형식 고정)
                                                   │
      리포트 ◀── ④ 리포트 작성 (Claude) ◀── ③ 집계 (pandas: 숫자는 코드가 계산)
```

설계 포인트:
- **숫자는 코드가 계산**: 건수·비율·평균은 pandas로 계산하고, Claude에게는 "주어진 숫자만 쓰라"고 지시 → AI가 숫자를 지어내는 문제를 막음
- **구조화된 출력**: 카테고리를 JSON 스키마의 `enum`으로 고정해 목록에 없는 카테고리가 나오지 않음
- **누락 재시도**: 묶음 처리에서 빠진 응답은 한 번 더 분류
- **개인정보 가리기**: 전화번호·이메일은 API로 보내기 전에 `[전화번호]`, `[이메일]`로 바꿈
- **effort 조절**: 분류는 `low`, 리포트는 `medium` — 품질을 지키면서 비용 절감
- **자동 재시도**: Opus 5에서 안전 필터가 요청을 거절하면 서버가 다른 모델로 다시 처리 (`fallbacks`)

## 크몽 서비스와의 연결

| 크몽 패키지 | 이 도구로 하는 일 |
|-------------|-------------------|
| 기본 | `--categories`로 고객이 준 기준 분류 → 엑셀 |
| 표준 | AI 기준 제안 → 고객 확인 → 분류 + 리포트 |
| 프리미엄 | 표준 + 이 스크립트와 설명서를 고객 환경에 맞춰 전달 |

## 콘텐츠 포인트

- 100개 응답을 몇 분 만에, API 비용 얼마에 — 실행 화면 녹화
- 사람이 직접 분류한 결과와 AI 결과 비교 (정확도 검증 편)
